뉴욕항 경유·휘발유 현물가 기준
 
계산 방식 · 가정 바꾸기

① 국제 도매가(원/L) = 뉴욕항 현물가($/갤런) × 환율 ÷ 3.785  ② 유가가 p% 오르고 환율이 d원 오르면 도매가는 (1+p) × (환율+d) ÷ 환율 배로 바뀝니다.  ③ 도매가가 변한 만큼 × 반영 비율이 주유소 평균가와 입력한 면세유 단가에 똑같이 더해진다고 가정합니다. 세금·유통마진은 고정이고 부가세 등은 반영하지 않았습니다. 실제 가격은 반영 시차, 계약, 정부 정책의 영향을 받으므로 방향과 규모를 가늠하는 참고용입니다.

100% = 도매가 변화분이 그대로 국내 가격에 반영

· 일반 주유소 평균(오피넷)은 유류세·부가세가 모두 포함된 소비자 가격입니다. 면세유와의 차이는 대체로 면제된 세금만큼입니다.

· 국제가격은 발표가 며칠 늦습니다. 각 값의 기준일을 함께 확인하세요. 수집에 실패하면 마지막으로 성공한 값을 회색으로 표시합니다.

수집 주기

  • 매시간 1회 자동 수집 (GitHub 사정에 따라 수 분~수십 분 지연 가능). 필요하면 즉시 수동 수집도 가능합니다.
  • 화면은 접속할 때마다 API를 부르지 않고 마지막 수집값을 보여줍니다. 수집 시각은 우측 상단에 표시됩니다.
  • API 하나가 실패해도 그 항목만 직전 값으로 유지되고 나머지는 정상 갱신됩니다.

왜 이렇게 만들었나요?

  • 웹페이지가 공공 API를 직접 부르면 브라우저 보안 정책(CORS)에 막힙니다. 그래서 GitHub Actions가 대신 받아 와서 화면에 넘겨줍니다.
  • 별도 서버를 설치·운영하지 않고, API 인증키는 GitHub에 비공개로 보관됩니다.
  • 면세유 단가는 공개 API가 없어 담당자가 수협 공지값을 직접 입력합니다.
